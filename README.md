# Simple-ATM-Simulation
This is an old project I made that simulates a simple ATM system using C++. 

# System Requirements:
To run this project on your device, you should have the following: 
 - A compiler that supports C++ (g++)
 - GNU Make
 - A Linux Evironment or Windows Subsystem for Linux (WSL)

# Installation of Ubuntu/WSL
Install the required tools with the following commands on WSL: 
 - sudo apt update
 - sudo apt install build-essential
